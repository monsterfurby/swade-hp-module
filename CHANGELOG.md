- Classic hit point system using Vigor as hit die
- Automatic HP calculation for new characters
- HP advancement system with dice rolling
- NPC HP support with arbitrary values
- Character sheet integration
- NPC sheet integration
- Module settings for customization
- Chat integration for HP advancement rolls

- HP starts at maximum Vigor die value
- Each advance adds another hit die roll
- Manual HP advancement button
- +/- buttons for easy HP adjustment
- Automatic initialization for existing characters
- Responsive design for mobile compatibility
- Localization support for multiple languages
